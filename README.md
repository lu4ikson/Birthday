# Birthday

Android-приложение для хранения дней рождения.

## Technologies

- Java
- Android Notifications
- Room (SQLite)
- LiveData
- Минимальная версия Android 10 (API 29)

## Возможности
Главный экран со списком ближайших дней рождения: вчерашние, сегодняшние и на ближайшие 7 дней. Пример строки: через 2 дня (22.05) будет день рождения Виктор (27 лет)
Дата с годом или без: если год рождения неизвестен, возраст просто не показывается.
Добавление человека через диалоговое окно: имя (произвольная строка, например «Сергей» или «Павел Андреевич») и дата рождения.
Полная база: отдельный экран со всеми сохранёнными днями рождения (рассчитано на 50-100 человек).
Уведомления:
в день рождения, каждый раз в 12:00;
за день до, по галочке «уведомить за день до», с выбором времени пуша.
Данные хранятся локально на устройстве, без регистрации и интернета.

## Планы

- Импорт контактов из телефонной книги
- Резервное копирование и восстановление базы данных
- Поиск по имени во всей базе
